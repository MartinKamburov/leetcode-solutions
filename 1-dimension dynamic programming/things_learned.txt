
At a high level dynamic programming eliminates the repeated work of something like a fibonacci sequence
by using caching. 

fibonacci solution:
    def bruteForce(n):
        if n <= 1:
            return n

        return bruteForce(n - 1) + bruteForce(n - 2)

A Top Down Dynamic Programming approach uses memoization:
    An example of top down (memoization):
        def memoization(n, cache):
            if n <= 1:
                return n
            if n in cache:
                return cache[n]

            cache[n] = memoization(n - 1) + memoization(n - 2)
            return cache[n]

    Dynamic programming in the end is just the fibonacci sequence with caching
    To solve some approaches in future problems think of it as recursion + caching

A Bottom Up Dynamic Programming approach doesn't use recursion:
    An example of bottom up:
        def dp(n):
            if n < 2:
                return n

            dp = [0, 1]
            i = 2
            while i <= n:
                tmp = dp[1]
                dp[1] = dp[0] + dp[1]
                dp[0] = tmp
                i += 1
            return dp[1]

Dynamic programming problems can be broken into two things:
    1. Overlapping subproblems
    2. Optimized substructures
